## 插卡

连接 Wi-Fi，首次使用需要打开美国代理，然后插卡。

- **iPhone**：设置 → 蜂窝网络 → Wi‑Fi 通话 → 打开**在 iPhone 上启用 Wi‑Fi 通话**（默认 E911 地址已填写，无需再重新填写），等信号处显示 T-Mobile Wi-Fi 即可。
- **安卓**：设置 → 移动网络 → 点击号码 → 打开**启用WLAN通话**。

注：安卓手机在部分地区或运营商会限制，例如小米通常需要在拨号界面输入代码 `*#*#869434#*#*` 来解锁并开启 Wi-Fi Calling 功能。输入后提示“VoWiFi Carrier Check was disabled”，随后可在设置中启用。

## 充值

1. 开启代理，打开 https://prepaid.t-mobile.com/direct-to-account 输入两次手机号码；
2. 点击 **Pay without logging in**（无需登录即可付款），输入充值金额，建议不低于 3 美元；
3. 输入 VISA 或 MasterCard 标志的信用卡信息，点击 **Accept & Submit**（接受并提交）进行充值。

注：如果出现报错，更换干净美国代理/VPN 节点。
