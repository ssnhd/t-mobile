## 插卡

1. 首次使用需要打开美国代理，然后插卡；
2. iPhone 连接 Wi‑Fi →【设置】→【蜂窝网络】→【Wi‑Fi 通话】→ 打开【在 iPhone 上启用 Wi‑Fi 通话】，默认 E911 地址已填写，无需再重新填写。
3.等待信号处显示 T-Mobile Wi-Fi 即可使用。

注： 安卓手机连接 Wi‑Fi →【设置】→【连接/网络】→【Wi‑Fi 通话】→ 选择【优先 Wi‑Fi】。

## 充值

1. 打开 https://prepaid.t-mobile.com/direct-to-account 输入两次手机号码；
2. 点击 **Pay without logging in**（无需登录即可付款），输入充值金额，建议不低于 3 美元；
3. 输入 VISA 或 MasterCard 标志的信用卡信息，点击 **Accept & Submit**（接受并提交）进行充值。

注：如果出现报错，更换干净美国代理/VPN 节点。
